# Задачи

Список от 2026-09-03, заменяет предыдущий.

## 0. Сквозное

«Сегодня» везде по проекту (личная панель, `/stats`, админ-панель) — это
скользящие 24 часа, а не календарные сутки. Сейчас день считается по
часовому поясу пользователя (`day_start_utc`), как в итоге дня было раньше —
меняем на ту же логику, что уже применили к саммари.

## 1. Панель юзера (в личке)

1. Меню One/Series/PC — по кругу (клик = следующее значение), без подменю.
2. Кнопка подключения при статусе «требует подключения».
3. Баг: `justdrunkzero` после реконнекта — геймерскор 0, бот пишет «всё ок»,
   хотя явно не всё ок.
4. Подтверждение при отключении от бота.
5. Последние 5 ачивок (не 1), в какую игру играет сейчас.

## 2. Панель админа

1. Сколько токенов Xbox API осталось / потрачено — лимиты.
2. Порог редкости — ручной ввод числа, не кнопки.
3. По чатам — список подписанных юзеров.

## 3. Саммари

1. Вертикальные разделители столбцов, чтобы не сливалось.

## 4. Панель бота (хаб группы — при `/help` и добавлении в чат)

1. Меньше кнопок: только 3 — «Публиковать мои», «Подключить Xbox», «Настройки».
2. Мини-инструкция в начале: сначала «Подключить Xbox», потом «Публиковать
   мои ачивки».
3. Если юзер перешёл по «Подключить Xbox» из конкретного чата — авто-subscribe
   в этот чат после успешного входа.
4. Список команд по блокам: ходовые (статистика и т.п.) — в начале,
   subscribe/unsubscribe — в конце; отписка тоже с подтверждением.
5. `/compare` — убрать.
6. Команда `/online` (или похожая) — все игроки чата и их статус Xbox
   (играет / не играет / во что играет). Ники кликабельные — открывают
   `/stats` этого игрока.
7. `/top` — убрать, есть в саммари.

**Правило:** не деплоить на сервер без предупреждения — только код и git.
