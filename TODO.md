# Задачи

Список от 2026-09-03. Все пункты ниже реализованы, закоммичены и запушены
в git — **на боевой сервер не выкатывались**, ждут отдельного разрешения.

## 0. Сквозное — ✅

«Сегодня» везде по проекту (личная панель, `/stats`, админ-панель) — теперь
скользящие 24 часа, а не календарные сутки, как и саммари.

## 1. Панель юзера (в личке) — ✅

1. One/Series/PC — по кругу одним тапом, без подменю.
2. Кнопка подключения при «требует подключения» / «не подключён».
3. Баг с геймерскором 0 после реконнекта — починен (`refresh_after_reconnect`
   в `bot/main.py`).
4. Подтверждение при отключении от бота (та же логика, что у `/disconnect`).
5. Последние 5 ачивок и «сейчас играет» вместо одной строки.

## 2. Панель админа — ✅

1. Живой снимок лимитов Xbox API — строка «API (ачивки)» на главном экране.
2. Порог редкости — ручной ввод числа вместо кнопок.
3. В карточке чата — список подписанных.

## 3. Саммари — ✅

1. Вертикальные разделители столбцов (`│`) и линия под шапкой — единый
   рендерер `bot/services/tables.py`, используют и `/stats`.

## 4. Панель бота (хаб группы) — ✅

1. Три кнопки: «Публиковать мои ачивки», «Подключить Xbox», «Настройки».
2. Мини-инструкция в начале хаба и `/help`.
3. «Подключить Xbox» из конкретного чата — авто-subscribe туда после входа.
4. Команды по блокам, ходовые в начале, subscribe/unsubscribe — в конце.
5. `/compare` — убран.
6. `/online` — статус всех игроков чата, ники кликабельные → `/stats`.
7. `/top` — убран, есть в `/summary`.
